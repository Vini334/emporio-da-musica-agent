# Data quality report

> Generated by `python -m emporio.data.prepare` (do not edit by hand). Reference date for late orders: **02/11/2026**.

The raw data (`data/raw`) is never edited. The `data/processed` layer only **standardizes** (types, enums, parsed specs, fields normalized for search) and **flags** suspicious records; no content is rewritten or recalculated. Each finding below states the treatment adopted. The reasoning behind the decisions is in [`design-decisions.md`](design-decisions.md) (§5 and §6). The store data is in Portuguese, so quotes from it are kept as is.

#### Active products with no stock · _warning_

- **Records:** 96
- **What was seen:** 96 Giannini GF-3D Dreadnought Sunburst

#### Upcoming releases (`coming_soon`) · _conflict_

- **Records:** 130
- **What was seen:** 130 Kala KA-ABP-CTG Barítono Cedar (stock 2); orders that already include it: 3 (delivered), 14 (pending). A product not yet released should not have orders.
- **Treatment:** Presented as coming soon, not for sale and with no promised date (BR-01). Existing orders can still be looked up normally.

#### Specs follow different schemas per instrument type · _info_

- **What was seen:** The `specs` JSON has no single schema: acoustic guitars/ukuleles, electric guitars/basses, drums and keyboards use different keys.
- **Treatment:** Specs are parsed into a dict and get a `specs_schema` field; the summary shown to the customer is built per schema.

#### A batch of products from another source · _info_

### Policy manual (PDF)

#### Two numbers presented as WhatsApp · _conflict_

- **What was seen:** Numbers in the manual: (67) 3321-4500, (67) 3341-4444. §1.2 lists "Telefone / WhatsApp" and §7 gives another number as the WhatsApp channel.
- **Treatment:** WhatsApp = (67) 3321-4500 (the channel's own section); phone = (67) 3341-4444 (BR-12, DD-§6).

#### E-mail with an accent in the domain · _conflict_

- **What was seen:** E-mails in the manual: `contato@emporiodamusica.com.br`, `contato@empóriodamusica.com.br`.
- **Treatment:** Uses `contato@emporiodamusica.com.br` (cover page); the accent is treated as a typo (BR-12, DD-§6).

#### Contradictory minimum installment between §3 and §3.1 · _conflict_

- **What was seen:** The §3 table says "parcela mínima de R$ 100,00" (minimum installment) for all credit purchases; §3.1 defines tiers. Minimums cited: R$ 50,00, R$ 80,00, R$ 100,00.
- **Treatment:** §3.1 prevails (more specific): 1–3x R$ 50,00 · 4–6x R$ 80,00 · 7–12x R$ 100,00 (BR-05, DD-§6).

#### Catalog size · _conflict_

- **What was seen:** The manual (§1) says "mais de 300 instrumentos" (more than 300 instruments); the system has 65 products.
- **Treatment:** The system prevails; the agent never claims to have what is not in it.

#### Shipping for exactly R$ 500,00 is not covered · _warning_

- **What was seen:** §5.1: free "acima de R$ 500,00" (above) and R$ 35,00 "abaixo de R$ 500,00" (below).
- **Treatment:** Up to R$ 500,00 inclusive pays R$ 35,00; free only above (BR-07).

#### Black Friday announced for November × promotions in the system · _warning_

- **What was seen:** The manual (§6.1) promises a November Black Friday with 15% to 30% off "em todo o catálogo" (the whole catalog); the system has only 4 active promotions, and every Black Friday one is inactive.
- **Treatment:** The system prevails: only promotions with `is_active = 1` (manual §7.3, DD-§6).

## Processed layer (`data/processed`)

One JSON per table (`ensure_ascii=False`, dates in ISO 8601). Added fields:

- `products`: `name_normalized`, `brand`, `category_name`, `specs` (objeto), `specs_schema`, `description_conflict`, `description_conflict_reasons`, `search_text`.
- `customers`: `first_name`, `phone_digits`, `email_normalized`.
- `orders`: `payment_type`, `installments`, `items_total_brl`, `total_mismatch`, `pix_without_discount`, `installment_below_minimum`.
- `order_items`: `unit_price_brl` and `line_total_brl` (**current** catalog price).
- `promotions`: `is_active` as a boolean.
- `policy_pages.json`: the text of each manual page, with spacing fixed (`pypdf` returns one word per line).
